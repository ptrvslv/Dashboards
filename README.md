## 📌 Описание проекта
Интерактивный дашборд для анализа основных бизнес-показателей сервиса Яндекс Афиша. Проект направлен на изучение пользовательской активности, динамики продаж билетов, оценки эффективности маркетинговых каналов и выявления ключевых факторов, влияющих на выручку.

**Цель:** Оценить ключевые метрики продукта (посещаемость, конверсию, средний чек, LTV и когортный анализ) и подготовить аналитические выводы для оптимизации маркетингового бюджета.

## 🛠 Стек технологий и архитектура

* **Визуализация:** Yandex DataLens
* **СУБД / Источник:** PostgreSQL / ClickHouse
* **Предобработка данных:** Python (Pandas, NumPy), SQL
* **Моделирование данных:** SQL-витрина данных (Data Mart)

### Схема обработки данных:
`Сырые логи и транзакции` ➔ `Очистка и агрегация в Python / SQL` ➔ `СУБД` ➔ `Подключение и вычисляемые поля в DataLens` ➔ `Интерактивный дашборд`

---

## 📊 Ключевые вычисляемые поля (DataLens)

Для расчета бизнес-метрик в DataLens были настроены вычисляемые поля:

* **Conversion Rate (CR):** `COUNT([order_id]) / COUNT([session_id])`
* **Average Order Value (AOV):** `SUM([revenue]) / COUNTD([order_id])`
* **ROMI / ROI:** `(SUM([revenue]) - SUM([costs])) / SUM([costs])`

---

## 💡 Ключевые инсайты

1. **Динамика продаж:** Основной пик выручки приходится на выходные дни и праздничные периоды, при этом категория «Театры и Концерты» формирует наибольшую долю среднего чека.
2. **Маркетинговые каналы:** Наиболее окупаемым каналом привлечения клиентов оказался ораганический трафик и контекстная реклама, в то время как социальные сети требуют пересмотра таргетинга.
3. **Когортный анализ:** Повторные покупки наиболее активны в первые 30 дней после регистрации, после чего требуется внедрение ретеншн-механик (email-рассылки, персонализированные скидки).
